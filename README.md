# 門徒健康檢視測驗

一個 36 題的個人檢視測驗，呈現三組分數及最需要被幫助的三項。這是照鏡子，不是人格診斷。作答進度只保存在目前瀏覽器的 sessionStorage，不會傳送到伺服器；按「重新作答」可清除。

## 題庫來源

《門徒健康檢視測驗 - 36 題規格與題庫 v1.0.md》。

## 修改題目

用文字編輯器開啟 `index.html`，找到 JavaScript 的 `questions`，依 Q 編號修改對應文字。`order` 決定出題順序；`itemForQuestion` 決定每三題所屬的項目。結果文字放在 `items`，每列依序為編號、名稱、一句辨識、經文、福音怎麼說、這週操練。修改時請同步核對規格與計分。

## 本機開啟

直接用瀏覽器開啟 `index.html` 即可，不需要安裝套件或連網。
